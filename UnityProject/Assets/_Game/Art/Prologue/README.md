## 품종별로 전부 뽑았습니다

강아지를 고르고 그 강아지로 스토리가 돌아가도록, 1~4번 컷을 **7품종 각각**
다시 렌더했습니다. 5번 컷(언덕과 집)은 강아지가 없어서 한 장을 공유합니다.

```
Art/Prologue/retriever/prologue_1..5.png
Art/Prologue/shiba/ · maltese/ · bordercollie/ · samoyed/ · bernese/ · poodle/
Art/Prologue/prologue_5_summit.png        (공용, 위 폴더에도 복사해 둠)
Art/Sprites/<품종>_front48_sheet.png      48x48 x 6칸
Art/Sprites/<품종>_leap80_sheet.png       80x56 x 2칸
```

품종별 색은 **하드코딩하지 않았습니다.** 각 품종 시트에서 직접 읽습니다 —
외곽선은 투명 픽셀에 닿는 색, 주된 털색은 가장 많이 쓰인 색, 나머지는
명도 순으로 그늘·하이라이트·크림·귀에 배정됩니다. 새 품종 시트를
폴더에 넣으면 코드를 안 고쳐도 됩니다.

두 가지는 품종에 따라 자동으로 달라집니다.

- **탠 포인트** — 시트에 털색과 색상이 뚜렷이 다른 색이 있으면(버니즈의
  `#BA6230`) 눈썹·볼·발목에 찍습니다. 나머지 품종은 해당 없음.
- **밤 색 보정** — 밝은 털은 60%로 낮추지만, 보더콜리·버니즈처럼 이미 어두운
  털은 96%만 적용합니다. 40%를 더 깎으면 상자 안이 그냥 검은 구멍이 됩니다.

## 스토리 흐름 (컷 순서)

| 컷 | 내용 |
|---|---|
| 1 | 비 그친 골목. 가로등 아래 젖은 상자 **안**에 작은 것이 웅크려 있다 |
| 2 | 상자 앞까지 다가감. 강아지가 앞모습으로 올려다본다 (목줄 + 이름표) |
| 3 | **손을 내밀자 강아지가 상자 밖으로 튀어나간다.** 아직 아무것도 안 했는데 |
| 4 | 한참 떨어져서 이쪽을 본다. 걸음을 옮기면 그만큼 떨어져 따라온다 |
| 5 | **세 단을 꺾어 올라가는 비탈 꼭대기**의 집 (보내주신 그림). 유일하게 밝은 컷 |

제안 나레이션 (확인 부탁드립니다):

1. 비가 그친 골목 끝, 가로등 아래 젖은 상자 안에 작은 것이 웅크리고 있었다.
3. 손을 내밀자 강아지가 상자 밖으로 튀어나갔다. 아직 아무것도 하지 않았는데.
4. 한참 떨어져서 이쪽을 보고 있었다. 걸음을 옮기자, 그만큼 떨어져서 따라왔다.

## 강아지 픽셀의 출처

```
retriever48_sheet.png → idle(4번) / jump(6번) / falling(7~) 프레임을 직접 읽음
  → 밤 장면은 10색을 명도만 내린 10색으로 치환
  → 정수배(x1~x5)로만 확대해 플레이트에 찍음
```

시트에 없는 포즈만 새로 그렸습니다 — **앞모습**과 **도약**. 도약도 머리는
시트 픽셀 그대로이고, 새로 그린 건 몸통·다리·꼬리·목줄뿐입니다.

## 카메라 구도 시작값

PPU 100, 플레이트 7.5 x 13 유닛, 중심 (0,0), `size` 는 시야 배수(1.0 = 650px).

| 컷 | 시작 at | 시작 size | 끝 at | 끝 size | 움직임 |
|---|---|---|---|---|---|
| 1 | (0.00, 0.20) | 1.9 | (−0.10, −3.60) | 1.0 | 골목 전경에서 상자로 |
| 2 | (−0.01, −1.30) | 1.3 | (0.10, −2.90) | 0.70 | 상자 전체 → 이름표로 푸시인 |
| 3 | (−0.03, −0.80) | 1.0 | (−0.03, −0.80) | 0.86 | 느린 푸시인. **손과 강아지 사이 틈을 깨지 마세요** |
| 4 | (−0.13, −3.57) | 1.0 | (−0.13, −3.57) | 1.0 | 고정. 둘 다 한 프레임에 |
| 5 | (−0.55, −5.90) | 1.0 | (0.25, −1.50) | 1.1 | 길 아래에서 집까지 위로 |
