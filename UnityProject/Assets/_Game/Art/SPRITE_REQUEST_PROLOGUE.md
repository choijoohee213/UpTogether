# 스프라이트 요청서 — 프롤로그 (발견 장면)

목적: 게임이 시작되기 전에 **"이 강아지는 버려졌다"는 설정을 주는 것.**

이게 없으면 본편에서 강아지가 멀찍이 떨어져 걷고, 떨어져도 안 오고, 뛰기 전에
멈칫하는 것이 **상처가 아니라 AI 결함으로 읽힌다.** 실제로 그렇게 읽혔다 —
1단계를 배포하고 확인한 결과다. 드라마는 설정 → 결과인데 결과만 있었다.

**그림 5장이면 된다.** 애니메이션도, 비도, 카메라 움직임도 그리지 않는다.

---

## 0. 안 그려도 되는 것

| 안 그릴 것 | 왜 |
|---|---|
| **비** | 코드 파티클로 뿌린다 |
| **카메라 움직임** | 플레이트 안을 카메라가 팬·줌 한다. 그림은 **정지화** |
| **애니메이션** | 프레임을 늘리면 컷 수만큼 곱해져 끝나지 않는다. **1장 = 1컷** |
| **레터박스** | 코드가 위아래 검은 띠를 깐다 |
| **글씨** | 코드가 아래에 띄운다. 그림에 글자를 넣지 말 것 |

움직이는 것은 전부 코드가 한다.

---

## 1. 크기 — 여기가 제일 중요하다

### 750 x 1300 px, **세로**

처음에 1400x1000 가로로 잡았다가 틀린 것을 발견했다. **게임이 세로 9:16 이다**
(`PlayerSettings.defaultWebScreen 450x800`, `index.html` 이 9:16 으로 가둔다).
가로 그림을 넣으면 **26% 만 보이고 양옆이 다 잘린다.**

계산 근거:
```
카메라 시야   650px 세로 (Tuning.cameraViewHeightPx), PPU 100
화면에 보이는 범위   366 x 650 px
플레이트를 그 2배로   → 750 x 1300  (= 7.5 x 13 유닛)
```

### 안전 영역

```
┌─────────────────────────┐  750 x 1300  (전체 그림)
│       팬 여유            │
│   ┌─────────────┐       │
│   │             │       │
│   │  366 x 650  │       │  ← 한 번에 화면에 보이는 크기
│   │  안전 영역    │       │     (시야 배수 1.0 기준)
│   │             │       │
│   └─────────────┘       │
│       팬 여유            │
└─────────────────────────┘
```

- **중요한 것(강아지·손·상자·집)은 가운데 366x650 안에** 넣는다
- 바깥쪽은 카메라가 훑고 지나갈 여유다. 비워도 되지만 **잘려도 어색하지 않게** 채운다
- 가로로 더 넓은 화면에서도 깨지지 않게, **좌우 끝 60px 는 중요한 것을 두지 않는다**

### 그 밖의 규격

| 항목 | 값 |
|---|---|
| 형식 | PNG 32bit. **배경 불투명** (화면을 꽉 채우는 판이다) |
| 스타일 | 픽셀아트. **안티앨리어싱 금지** |
| 픽셀 크기 | **1 그림픽셀 = 1 게임픽셀.** 본편 캐릭터가 48px 인 것을 기준으로 밀도를 맞춘다 |
| 외곽선 | 1px, `#4A4458` |
| 파일명 | `prologue_1.png` ~ `prologue_5.png` |
| 넣을 곳 | `Assets/_Game/Art/Prologue/` |

> 2배로 그려서 줄이지 말 것. 정수배가 아니면 픽셀이 뭉개진다.
> 크게 그리고 싶으면 **375x650 으로 그린 뒤 정확히 2배**로 키운다.

## 2. 팔레트

본편과 같은 색을 쓴다. 프롤로그는 **비 오는 밤**이라 명도만 내린다.

```
어두운 선 / 그림자    #4A4458
나무·흙 (밝은→어두운)  #E6BE8C  #DEAA76  #CDA070  #BA8054  #80543C
돌·금속 (밝은→어두운)  #D6D2E2  #AAA5BE
강조 (목줄 등)        #E87878
밝은 하이라이트        #FAE8BE
배경 어둠 (프롤로그 전용) #14171F  #1E2430  #2A3340
```

**채도를 빼지 말고 명도만 내린다.** 탁해지면 본편과 다른 게임이 된다.

## 3. 5장 — 내용

컷 순서 = 파일 번호. **시점이 3인칭과 1인칭으로 교차한다.**
멀리서 보다가 갑자기 내 눈이 되는 순간이 있어야 3번이 남의 일이 아니게 된다.

---

### `prologue_1.png` — 3인칭 · 비 내리는 거리

> 비 내리는 거리 끝, 젖은 상자 옆에 작은 것이 웅크리고 있었다.

세로 화면이라 **건물을 높게 세워** 거리를 만든다. 위 2/3 가 건물과 밤하늘,
아래 1/3 이 젖은 길. 가로등 하나가 유일한 빛.

- 젖은 종이상자 — 아래쪽이 물을 먹어 색이 짙다
- 그 옆에 **아주 작게** 웅크린 것. 이 컷에서는 개인지도 잘 안 보일 만큼 작아도 된다
- 인물은 없거나 멀리 실루엣만

**읽혀야 할 것:** 춥고, 비 오고, 아무도 없다.

---

### `prologue_2.png` — 1인칭 · 상자를 내려다봄

> 목에 낡은 목줄이 남아 있었다. 이름 칸은 지워져 있었다.

**눈높이가 바뀌는 첫 컷.** 사람 키에서 상자를 내려다보는 각도(위에서 45도쯤).
상자 입구가 화면을 거의 채우고, 그 안에 강아지가 **위를 올려다본다.**

- **낡은 목줄과 지워진 이름 칸이 또렷하게 보여야 한다.** 이 장면의 전부다
- 이름 칸은 긁혀서 지워졌거나 글자가 뭉개진 금속 조각
- 강아지 표정: 겁먹었지만 **불쌍하게 그리지 않는다** (아래 4장 참고)

**읽혀야 할 것:** 이 개는 누군가의 개였다. 그리고 버려졌다.

---

### `prologue_3.png` — 1인칭 · 손을 내민다  ★ 핵심

> 손을 내밀자 강아지가 움츠렸다. 아직 아무것도 하지 않았는데.

**이 기획의 전부가 이 한 장이다.**

- **내 손이 화면 아래에서 올라온다.** 손바닥을 펴고 천천히 내민 손
- 강아지는 **구석으로 물러나** 벽에 붙어 있다. 귀는 뒤로 접히고 몸은 낮다
- 손과 강아지 사이에 **닿지 않는 거리**가 있어야 한다. 그 틈이 이 그림의 주인공이다
- 가장 가까이 들어가는 컷 — 둘 다 크게

**절대 그리지 않는 것:** 때리는 손, 치켜든 손, 상처, 피, 멍, 울음.
**폭력은 한 조각도 그리지 않는다.** 그리는 것은 *아직 아무것도 하지 않은 손*과
*그래도 물러나는 개* 뿐이다. 나머지는 보는 사람이 채운다 — 그게 이 장면이
작동하는 방식이고, 그리는 순간 싸구려가 된다.

---

### `prologue_4.png` — 3인칭 · 한참 떨어져서 따라온다

> 그래도 걸음을 옮기자, 한참 떨어져서 따라왔다.

다시 멀어진다. **거리가 보여야 하는 컷.**

세로 화면이라 좌우로 벌리면 한 화면에 안 들어온다. **원근으로 거리를 만든다** —
인물은 가깝고 크게(앞서 있다), 강아지는 멀고 작게(한참 뒤).

- 인물은 뒷모습이나 옆모습, 걸어가는 중
- 강아지는 따라오긴 하는데 **따라붙지는 않는다**
- 둘 사이가 비어 있어야 한다. 그 빈 공간이 본편의 100px 거리로 이어진다

**읽혀야 할 것:** 따라오긴 한다. 그런데 가까이 오지는 않는다.

---

### `prologue_5.png` — 3인칭 · 길 끝의 언덕과 빈 집

> 길이 끝나는 곳에 언덕이 있었다. 그 위에 빈 집이 하나 있다.

거리 → 언덕. **게임 맵으로 넘기는 컷.**

- 둥근 언덕 능선 (피라미드처럼 각지면 안 된다)
- 그 위에 작은 **2층 강아지집**. 본편 `Identity/goal_doghouse_2f.png` 와 같은 실루엣으로
- **비어 있어 보여야 한다** — 불이 꺼져 있고 문이 열려 있다
- 아래에서 언덕으로 길이 이어진다

**지평선 쪽 하늘이 트여야 한다.** 비가 그쳐 가고 밝아진다.
아크가 회복 쪽으로 간다는 첫 신호라서, 이 한 장만 밝다.

---

## 4. 톤 — 꼭 지킬 것

본편 톤은 "밝은 파스텔, 귀엽지만 과하지 않게"다. 프롤로그만 무거워지면 다른 게임이 된다.

1. **과거를 그리지 않는다.** 학대 장면, 전 주인, 버려지는 순간 전부 없다.
   낡은 목줄과 지워진 이름 칸, 그 둘이 과거를 말하는 유일한 물건이다. 충분하다.
2. **불쌍하게 그리지 않는다.** 겁먹은 것과 불쌍한 것은 다르다.
   큰 눈물, 처진 눈썹, 애원하는 눈 — 넣지 않는다. 그냥 **경계하는 개**다.
3. **어둡게 하되 탁하게는 하지 않는다.** 채도를 빼지 말고 명도만 내린다.
4. **5번은 밝아져야 한다.** 다섯 장이 전부 어두우면 회복 서사가 안 보인다.

---

## 5. 그려서 주시면 제가 할 일

1. `Assets/_Game/Art/Prologue/` 에 5장을 넣는다
2. **UpTogether ▸ Import Prologue Art** — PPU 100 / Point / 무압축으로 자동 설정
3. **UpTogether ▸ Build Prologue Scene** — 플레이트를 자동으로 꽂는다
   (그림이 있으면 자리표시 판과 눈금을 안 만든다)
4. `PrologueScene.Shots()` 의 `at` / `size` 를 **그림에 맞춰 구도를 잡는다**
   — 지금 값은 자리표시 기준이라 그림이 오면 다시 맞춘다
5. 웹 빌드 → 배포

**그림이 없는 동안에도 씬은 돌아간다.** 지금은 단색 판에 "[1인칭] 컷 3/5 · 그림 자리 /
내 손이 프레임에 들어옴 — 강아지가 뒤로 움츠림" 처럼 적혀 있어서,
구성과 타이밍은 먼저 확인할 수 있다.

### 한 장씩 줘도 된다
5장을 다 기다리지 않는다. `prologue_1.png` 만 넣고 임포트해도 그 컷만 그림으로
바뀌고 나머지는 자리표시로 남는다.
